# 🛒 KnockYourDoor

KnockYourDoor is a modern E-Commerce and Delivery Web Application built using HTML, CSS, and JavaScript.

The platform provides a complete online shopping experience with product browsing, search functionality, cart management, order tracking, and user profile management.

---

## 🚀 Features

- User Login & Registration
- Product Catalog
- Product Search
- Product Details Page
- Shopping Cart
- Order Management
- User Profile
- Responsive Design
- Modern UI/UX

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
